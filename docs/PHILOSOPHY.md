# DevicePulse Philosophy

DevicePulse exists to help people understand their Android devices.

We believe:

- Accuracy is more important than impressive numbers.
- Honest limitations build trust.
- Good software explains itself.
- Simplicity beats unnecessary complexity.
- Documentation is part of the product.
- Tests are features.
- Architecture is a user feature because maintainable software stays reliable.

DevicePulse will never:

- Fake optimization
- Invent unavailable data
- Exaggerate hardware improvements
- Sacrifice clarity for marketing

Every feature should answer one question:

"Does this genuinely help the user understand their device?"
