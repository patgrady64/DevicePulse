# DevicePulse UI Guidelines

The goal of DevicePulse is to create an interface that is calm, readable, informative, and trustworthy.

---

# Design Principles

- Simplicity over decoration
- Information before graphics
- Consistency over novelty
- Accessibility first

---

# Cards

Every dashboard card should contain:

- Icon
- Title
- Primary value
- Supporting information

Cards should use consistent spacing and corner radius.

---

# Typography

Primary Metric

Large

Bold

Easy to scan

Secondary Information

Medium weight

Smaller than primary metric

Labels

Consistent size

Muted emphasis

---

# Spacing

Use 8dp spacing units.

Common values:

8dp

16dp

24dp

32dp

---

# Icons

Icons should clarify information, not decorate the interface.

Prefer Material Symbols.

---

# Colors

Green

Healthy

Blue

Informational

Amber

Warning

Red

Critical

Gray

Unavailable

Never rely on color alone.

---

# Unavailable Data

Never display fake values.

Use:

Unavailable

Unknown

Not Supported

depending on the situation.

---

# Animations

Animations should be subtle.

Never animate purely for decoration.

Animations should communicate state changes.

---

# Accessibility

Support screen readers.

Large touch targets.

High contrast.

Dynamic font sizes.

---

# Dark Mode

Every feature must support Light and Dark themes.
